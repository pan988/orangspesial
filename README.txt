Cara pakai:
1. Buka folder ini di VS Code, klik kanan index.html > Open with Live Server (atau klik dua kali index.html).
2. Ganti nama, kode rahasia, tanggal, pesan, foto, dan lagu di blok 'const C' paling atas file script.js.
3. Taruh foto dan mp3 di folder assets, lalu isi 'src' dengan 'assets/namafile.jpg' atau 'assets/lagu.mp3'.
